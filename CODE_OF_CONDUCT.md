# Code of Conduct

This project is committed to providing a welcoming and respectful environment for everyone.

## Expected behavior

- Be respectful and inclusive.
- Use welcoming and constructive language.
- Accept feedback gracefully.
- Focus on what is best for the community.

## Unacceptable behavior

- Harassment, discrimination, or personal attacks.
- Trolling, insulting comments, or sustained disruption.
- Publishing others' private information without permission.
- Any behavior that would reasonably be considered inappropriate in a professional setting.

## Reporting

If you experience or witness unacceptable behavior, report it through the repository maintainers or the public issue process defined for the project.

# Public task cards

The four task cards are derived from SWE-bench Verified and contain only public repository metadata. Each card records the SWE-bench instance identifier, upstream repository and base commit, functional test selector, difficulty, task type, brief public problem statement, and seeded architecture rules.

- `PUB-DJANGO-O2O`: `django__django-15278`
- `PUB-SKLEARN-OUTPUT`: `scikit-learn__scikit-learn-25747`
- `PUB-SPHINX-NAPOLEON`: `sphinx-doc__sphinx-9673`
- `PUB-XARRAY-TIMEDELTA`: `pydata__xarray-6599`

`tasks.json` is the combined machine-readable form. Individual JSON files contain identical records for easier reuse. Upstream code, gold patches, hidden test patches, and agent patches are not included.

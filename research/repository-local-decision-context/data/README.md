# Released data

- `public_run_results.csv` and `.json`: 18 de-identified public-task outcomes.
- `aggregate_public_18.json`: summary reproducible from the released CSV.
- `aggregate_all_32.json`: approved aggregate summary for all corrected-v2 outcomes.

The 32-run aggregate includes 14 withheld private-task outcomes. No private task identifier, run identifier, repository, prompt, patch, trace, or free-text content is released. Consequently, only the 18-run public-subset summary is independently reproducible from run-level data in this package.

See `../DATA_DICTIONARY.md` for field definitions and `../protocol/` for design deviations.

## Release sequence

1. Build and audit the public-only bundle locally.
2. Add the bundle under an approved research path in the GitHub repository.
3. Open and review a pull request.
4. Merge and record the exact commit SHA.
5. Create a stable Git tag and release archive.
6. Upload the audited tagged artifact to the reserved Zenodo draft.
7. Publish Zenodo and verify the DOI resolves.
8. Confirm that the manuscript's Data and Code Availability statements match the published release.

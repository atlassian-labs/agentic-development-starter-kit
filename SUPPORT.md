# Support and Triage

Use the public repository issue tracker for questions, bugs, and contribution proposals.

## Triage process

Maintainers review incoming issues and pull requests on a regular cadence. Security-sensitive reports should not be posted publicly; use the security reporting process configured for the repository.

## Contribution response expectations

- Bugs: reviewed for reproduction steps and impact.
- Feature requests: reviewed for fit with the starter-kit scope.
- Pull requests: reviewed for correctness, documentation quality, and external-share safety.

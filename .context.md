## Code Style

### JavaScript
- **Module system:** CommonJS only (`require`/`module.exports`) — no ES modules, no TypeScript
- **Async:** `async/await` — no raw Promises, no callbacks
- **Error handling:** try/catch in route handlers; let errors bubble from services
- **Naming:** camelCase for variables/functions, PascalCase for classes/components, UPPER_SNAKE for constants

### React
- **Components:** Functional components with hooks only — no class components
- **State:** `useState`, `useEffect`, `useContext` — no Redux, no MobX
- **Styling:** CSS modules or plain CSS — no CSS-in-JS
- **Props:** Destructure at function signature level

### Database
- **Connection:** Always use `src/database/connection.js` — never import `better-sqlite3` directly
- **Queries:** Always use parameterized queries — never string interpolation in SQL
- **Migrations:** Schema changes go in `src/database/migrations/` — never modify existing migrations

## Testing

```bash
# Backend (routes, services):
npx jest --testEnvironment=node

# Frontend (React components):
npx jest --testEnvironment=jsdom

# All:
npm run test:all
```

**Rules:**
- Never modify a test to make your code pass
- Test files live next to the code they test (`service.test.js` next to `service.js`)
- Use `jest.mock()` for external dependencies — never call real APIs in tests
- Minimum: happy path + at least one error path per function

## Production Safety Invariants

### Zero Mock Data in Production
Production code paths must contain zero mock/hardcoded data:

```javascript
// ❌ WRONG
const goals = process.env.NODE_ENV === 'test' 
  ? [{ id: 1, title: 'Mock Goal' }] 
  : await fetchGoals();

// ✅ RIGHT — show clear error state, no fake data
try {
  const goals = await fetchGoals();
  return goals;
} catch (err) {
  logger.error('Goals fetch failed:', err.message);
  return { error: 'Goals unavailable — check connection', goals: [] };
}
```

### Parameterized SQL Always
```javascript
// ❌ WRONG — SQL injection risk
db.run(`SELECT * FROM stories WHERE id = ${id}`);

// ✅ RIGHT
db.run('SELECT * FROM stories WHERE id = ?', [id]);
```

### API Backward Compatibility
Never break existing API routes without a migration plan:
1. Check if the route is used by frontend: `grep -r "api/your-route" src/frontend/`
2. Check if used by agents: `grep -r "api/your-route" src/backend/services/`
3. If used anywhere: add new route, deprecate old one gradually

## Agent Session Rules

The `GlobalServeManager` manages the single an AI coding agent session:

- **For interactive use:** `GlobalServeManager.chat(prompt)` — appends to session
- **For plan generation:** `GlobalServeManager._chatDirectFresh(prompt)` — resets session first
- **For background tasks (workflow stages):** Use `prompt_mode: 'replace'` in stage spec
- **Port:** Always port 9050 — if occupied, adopt existing instance, never start on 9051
- **Token:** Persisted to `logs/agent_session_token.json` — server auto-adopts on restart

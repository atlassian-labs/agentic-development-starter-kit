# Contributing

Thanks for your interest in improving the Agentic-First Development Starter Kit.

## How to contribute

1. Open an issue describing the change you want to make.
2. Fork the repository and create a feature branch.
3. Keep changes focused and include documentation updates when behavior changes.
4. Open a pull request with a clear description of the problem and solution.

## Review expectations

- Keep documentation clear and implementation-oriented.
- Avoid adding project-specific or organization-specific references.
- Do not include secrets, credentials, customer data, or private/internal links.
- Prefer examples that can be used by external readers without access to private systems.

## Code of conduct

Be respectful, constructive, and collaborative. Assume good intent and help keep the project welcoming for contributors.
